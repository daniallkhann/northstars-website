# Northstars Digital Solutions Website

Files:
- `index.html` — complete website
- `styles.css` — responsive styling
- `script.js` — mobile menu, category search/filtering, form notice

## Before publishing
1. Open `index.html` and replace `[BUSINESS EMAIL]` and `[PHONE NUMBER]`.
2. The contact form is front-end only. Connect it to your preferred form/email backend before expecting messages to be delivered.
3. Review all business, affiliate, legal, and provider statements before publishing and make sure they accurately describe how Northstars Digital Solutions operates.
4. Upload all three website files together, keeping their filenames unchanged.

The layout was recreated from the reference screenshots supplied in the conversation.


## Version 2 change
The Contact Us form has been removed from the main page. All Contact Us links now open `contact.html`, a separate contact page. Keep all files together in the same extracted folder when testing or publishing.
